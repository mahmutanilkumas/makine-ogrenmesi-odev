# Müşteri Ayrılma (Churn) Tahmini - Makine Öğrenmesi Ara Ödev

## Projenin Amacı
Bu proje, Türkiye Yapay Zeka Akademisi Makine Öğrenmesi Ara Ödevi kapsamında hazırlanmıştır. Temel bir sınıflandırma problemi olan "Müşteri Ayrılma Tahmini" üzerinden veri oluşturma, keşifçi veri analizi (EDA), veri ön işleme, öznitelik mühendisliği ve model eğitimi adımları uçtan uca uygulanmıştır.

## Kullanılan Teknolojiler
- Python 3
- Pandas & Numpy (Veri Manipülasyonu)
- Scikit-Learn (Makine Öğrenmesi Modelleri ve Metrikler)
